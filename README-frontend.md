# Frontend - Plastic Recycle (Vercel ready)

## Quick start (local)
1. cd frontend
2. copy .env.example -> .env and set REACT_APP_API_URL (e.g. http://localhost:5000/api)
3. npm install
4. npm start

## Deploy on Vercel
1. Push frontend folder to GitHub.
2. Import project into Vercel.
3. Set environment variable REACT_APP_API_URL to your Render backend URL + /api
